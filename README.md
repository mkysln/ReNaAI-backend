# ReNaAI Backend

ReNaAI Backend, kullanıcıların haftalık üretkenlik bilgilerini yapay zekâ destekli bir koçluk yanıtına dönüştürmek için geliştirilmiştir. İstemciden gelen veriyi alır, Groq üzerinden AI koç servisine iletir ve üretilen yanıtı geri sunar.

Projenin amacı, ReNaAI uygulamasındaki haftalık değerlendirme deneyimine sunucu tarafında bir AI bağlantısı sağlamaktır.
